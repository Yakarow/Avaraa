# Avaraa Kommunity

Static one-page site. No build step.

## Go live with GitHub Pages
1. Create a new GitHub repo and upload everything in this folder (index.html, assets/, .nojekyll).
2. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. After about a minute the site is live at https://YOUR-USERNAME.github.io/REPO-NAME/
